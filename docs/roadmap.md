# Roadmap

Current milestone: first alpha candidate `0.1.0-alpha.1` on Node 24.15+, Windows/Linux, with SQLite, service/dashboard/CLI, Codex adapter, demo mode, isolation, approval, result acceptance, recovery quarantine, credential-free tests, protocol smoke validation, and one-command foreground startup implemented. The source-install and offline-demo walkthrough is recorded in [release](release.md). Windows authenticated two-alias pilot validation and the Windows/Ubuntu CI suite are recorded in [validation](validation.md).

The remaining live gates are Linux authenticated isolation, quota exhaustion behavior, and logout/refresh isolation. Sandbox-only completion is also limited by the installed Windows provider, which rejected its shell and file-write requests under `approval_policy=never`; normal on-request approvals completed the pilot. Frequent provider approvals remain an operational limitation. Later work may add Claude, Grok, native subagents, remote nodes, stronger recovery, and release hardening.
