# Roadmap

Current milestone: local pre-alpha on Node 24.15+, Windows/Linux, with SQLite, service/dashboard/CLI, Codex adapter, demo mode, isolation, approval, result acceptance, recovery quarantine, credential-free tests, and protocol smoke validation implemented.

The remaining validation gate is opt-in authenticated testing with two already connected aliases, followed by Linux CI verification. Later work may add Claude, Grok, native subagents, remote nodes, stronger recovery, and release hardening.
