# Code of Conduct

Participants in this project must be respectful, assume good faith, and keep discussions focused on useful technical outcomes. Harassment, discrimination, threats, doxxing, sexualized conduct, and deliberate disruption are not acceptable.

Project maintainers may remove content or restrict participation when conduct harms the community or project. Use GitHub's built-in report-content controls for platform abuse. For a concern needing private maintainer discussion, request a private contact channel without publishing sensitive details. No separate confidential contact address is currently advertised.
