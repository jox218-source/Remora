# Support

Read the README and [docs/getting-started.md](docs/getting-started.md) first. For reproducible bugs, open a GitHub issue with the OS, Node version, command, sanitized output, and whether the run was `demo` or a real provider. Never attach credentials, tokens, account profiles, or private task snapshots.

Use feature requests for planned behavior and provider questions for adapter compatibility. Live provider failures may depend on the installed Codex app and account state; include the provider and app version when safe.
